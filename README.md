# Food Drying - Traduction française

French translation of [Food Drying [B42]](https://steamcommunity.com/sharedfiles/filedetails/?id=3747396551) by Corvus, for Project Zomboid Build 42.22.

- Mod id: `batman_FoodDryingFR` (requires `FoodDrying`, loads after `FoodDrying_VFEPatch` when present)
- Translated files: `Contents/mods/batman_FoodDryingFR/42.21/media/lua/shared/Translate/FR/*.json`
- Based on Food Drying 1.11 (250 keys: recipes, items, menus, drying rack, tooltips, sandbox options, VFE patch)

## Install

Subscribe on the Steam Workshop, enable Food Drying and this mod, and set the game language to Français.

## Updating the translation

When Food Drying adds or changes texts, compare its `Translate/EN` files (FoodDrying and FoodDryingVFEPatch) with the `FR` files here: same keys in the same files. Item and recipe names follow the vanilla French vocabulary (`Translate/FR/ItemName.json` of the game).

`source/make_poster.py` rebuilds the poster from the original Food Drying artwork (Pillow); `preview.png` is the poster resized to 256 px.
